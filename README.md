# Browser Piano

Virtuelles Klavier (3 Oktaven ab C) mit React, Vite und Tone.js.

- Spielen per Maus/Touch oder Computertastatur (Belegung steht auf den Tasten)
- Transpose ±12 Halbtöne (Buttons oder Pfeil hoch/runter)
- Klang: Salamander-Klaviersamples (Synth-Fallback, solange sie laden)

```
npm install
npm run dev
```
